مستندات اجرا

برای نسخه استاتیک، قیمت‌ها از data/prices.json خوانده می‌شوند. برای نسخه کامل می‌توانی همین ساختار را روی Firebase Hosting + Firestore ببری.

مدل سایت: مرجع عمومی قیمت. هیچ نام فروشگاه، پلن اختصاصی یا برند فروشنده نباید در قالب ثابت هاردکد شود.

مسیر کامل با Firebase

۱. Firebase Project بساز. ۲. Hosting را فعال کن. ۳. Firestore را برای collections قیمت‌ها و فروشنده‌ها بساز. ۴. اگر پنل ادمین خواستی Auth اضافه کن. ۵. فایل‌ها را Deploy کن.

npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy
BlueNerkh مرجع نمایش و مقایسه قیمت فروشنده‌هاست؛ فروشنده یا فروشگاه اختصاصی نیست.
